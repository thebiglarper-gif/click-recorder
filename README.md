# Click Recorder

Records your own clicks while you play a level and saves them as `.gdr2` click files. It can also play a click file back in the level.

## Pause menu

Press **Clicks** in the pause menu to open the panel:

- **Record / Pause**: start recording your clicks, or pause the recording.
- **Save**: save the clicks recorded so far.
- **Play / Stop**: restart the level and play the chosen click file, or stop it.
- **Open File**: choose which `.gdr2` file Play uses.
- **Recordings folder**: open the folder your recordings are saved in.

Turn on **Hide in pause menu** in the settings to remove the button. The keybinds keep working.

## Keybinds

| Action | Default |
| --- | --- |
| Record / Pause | Alt+R |
| Save | Alt+S |
| Play / Stop | Alt+P |
| Open File | Alt+O |

Change them in the mod's settings.

## Notes

- Recording starts automatically when a level opens. Turn off **Record automatically** to only record when you press Record.
- A file is saved automatically when you beat the level. Turn on **Save failed attempts** to also save runs where you die.
- Practice mode works: clicks after your last checkpoint are dropped when you respawn.
- Set **Ticks per second** to match your game if you use a TPS mod (normal GD is 240).
- Recording only watches your inputs and doesn't change gameplay. Replayed runs never save progress.
