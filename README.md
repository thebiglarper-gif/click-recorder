# Click Recorder

Records your own clicks while you play a level and saves them as a `.gdr2` click file when you beat it. Switch **Mode** to Replay and pick a file to play it back.

- Recordings go to the mod's save folder, in `recordings/`. Open it from the mod's page in Geode (the folder button).
- Practice mode works: clicks after your last checkpoint are dropped when you respawn.
- Turn on **Save failed attempts** in the settings to also save runs where you die.
- Set **Ticks per second** to match your game if you use a TPS mod (normal GD is 240).

Recording only watches your inputs and doesn't change gameplay. Replayed runs never save progress.
